Fix: Freeze/Activate card using correct StroWallet API
The freeze endpoint URL and parameters are wrong. Here's the correct implementation from StroWallet docs:
Correct endpoint:
POST https://strowallet.com/api/bitvcard/nfc-cards/status
Correct parameters (query string):

public_key ✅ required
card_id ✅ required
status ✅ required — value is "active" or "frozen" (NOT "action": "freeze/unfreeze")
mode — "live"

Note: NO secret_key needed for this endpoint!
Correct response:
json{
  "success": true,
  "message": "Card status updated successfully.",
  "response": {
    "card_id": "...",
    "status": "frozen"
  }
}

Fix in POST /api/cards/freeze (nfc-cards.ts):
typescript// Current wrong code (remove this):

console.log('[Card] Freeze response:', JSON.stringify(raw));

if (!raw.success) {

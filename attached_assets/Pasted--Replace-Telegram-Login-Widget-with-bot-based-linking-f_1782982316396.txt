
Replace Telegram Login Widget with bot-based linking flow
Instead of the Telegram Login Widget (which requires phone number entry), implement a simpler bot-based flow:

User clicks "Connect Telegram" button
Platform generates a unique 6-digit code for the user
User opens @xendrx_bot in Telegram and sends /start XXXXXX (the code)
Bot receives the code, matches it to the user, links their Telegram ID
Platform shows "Connected ✅"

Backend changes needed:
typescript// POST /api/profile/telegram-link-code
// Generates a unique code for the user
router.post('/telegram-link-code', userAuth, async (req, res) => {
  const code = Math.random().toString(36).substring(2, 8).toUpperCase();
  const expiresAt = new Date(Date.now() + 10 * 60 * 1000); // 10 minutes
  
  await db.insert(telegramLinkCodesTable).values({
    userId: req.userId,
    code,
    expiresAt
  }).onConflictDoUpdate({
    target: telegramLinkCodesTable.userId,
    set: { code, expiresAt }
  });
  
  return res.json({ code });
});

// In bot message handler — when user sends /start CODE:
bot.command('start', async (ctx) => {
  const code = ctx.message.text.split(' ')[1];
  if (!code) {
    return ctx.reply('Welcome to Xendrx! Send /start YOUR_CODE to link your account.');
  }
  
  const linkCode = await db.select()
    .from(telegramLinkCodesTable)
    .where(
      and(
        eq(telegramLinkCodesTable.code, code.toUpperCase()),
        gt(telegramLinkCodesTable.expiresAt, new Date())
      )
    )
    .limit(1);
  
  if (!linkCode[0]) {
    return ctx.reply('❌ Invalid or expired code. Please get a new code from the Xendrx website.');
  }
  
  // Link the Telegram account
  await db.insert(telegramUsersTable).values({
    userId: linkCode[0].userId,
    telegramId: String(ctx.from.id),
    username: ctx.from.username ?? null,
    firstName: ctx.from.first_name ?? null
  }).onConflictDoUpdate({
    target: telegramUsersTable.userId,
    set: { 
      telegramId: String(ctx.from.id),
      username: ctx.from.username ?? null 
    }
  });
  
  // Delete used code
  await db.delete(telegramLinkCodesTable)
    .where(eq(telegramLinkCodesTable.userId, linkCode[0].userId));
  
  // Notify the platform via SSE
  emitToUser(linkCode[0].userId, 'telegram_linked', { telegramId: String(ctx.from.id) });
  
  return ctx.reply('✅ Your Telegram account has been successfully linked to Xendrx!');
});

Fix: Billing address fields incorrect — collect real address during card creation
According to StroWallet API docs, card creation requires these billing address fields:

line1 — street address
city — city
state — state/region
postal_code — postal/zip code
country — 3-letter ISO code (e.g. ETH for Ethiopia)
phone — in local country format

Current problem:

All address fields are set to N/A and 00000 — wrong!
StroWallet accepted these but they are incorrect billing details
When user uses card for online purchases, billing address must match

Fix 3 — Backend uses real address fields:
In POST /api/cards/create:
typescript// Read from request body:
const { country, line1, city, state, postal_code, phone } = req.body;

// Validate required fields:
if (!line1 || line1 === 'N/A') {
  return res.status(400).json({ 
    success: false, 
    message: 'Street address is required for card creation' 
  });
}
if (!city || city === 'N/A') {
  return res.status(400).json({ 
    success: false, 
    message: 'City is required for card creation' 
  });
}
if (!postal_code || postal_code === '00000') {
  return res.status(400).json({ 
    success: false, 
    message: 'Postal code is required for card creation' 
  });
}

// Send to StroWallet:
params.set('line1', line1);
params.set('city', city);
params.set('state', state || city); // use city as state if not provided
params.set('postal_code', postal_code);
params.set('country', country || 'ETH');
params.set('phone', phone || user.phone);

console.log('[Card] Billing address:', { line1, city, state, postal_code, country });

Fix: Card fund showing "Card service configuration error" instead of queuing when StroWallet balance is insufficient
Current broken behavior:

User tries to fund card $10
StroWallet merchant balance is $6.45 (insufficient for $10)
Shows "Card service configuration error" ❌
Should show "Request queued" instead ✅

Fix in POST /api/cards/fund:
typescript// After calling StroWallet:
if (!raw.success) {
  console.log('[Card] Fund failed — StroWallet response:', JSON.stringify(raw));
  
  // Check if it's an insufficient balance error
  const isInsufficientBalance = 
    raw.message?.toLowerCase().includes('insufficient') ||
    raw.message?.toLowerCase().includes('balance') ||
    raw.required !== undefined ||
    raw.available !== undefined;

  // Check if it's a configuration error
  const isConfigError =
    raw.message?.toLowerCase().includes('configuration') ||
    raw.message?.toLowerCase().includes('public key') ||
    raw.message?.toLowerCase().includes('invalid key');

  if (isInsufficientBalance) {
    // Queue the request — DO NOT refund platform balance yet
    await db.insert(cardQueue).values({
      userId,
      cardId: card.cardId,
      type: 'fund',
      amount: amount.toString(),
      status: 'pending',
      errorMessage: raw.required 
        ? `StroWallet needs $${raw.required}, available $${raw.available}`
        : raw.message
    });

    console.log('[Queue] Fund queued for user:', userId, 'amount:', amount);

    // Notify admin
    console.log('[Queue] Admin alert — StroWallet balance low. Required:', raw.required, 'Available:', raw.available);

    return res.json({
      success: true,
      queued: true,
      message: `Your top-up of $${amount} has been queued. Your platform balance has been reserved and will be credited to your card automatically once service balance is restored. You will be notified when completed.`
    });
  }

  if (isConfigError) {
    // Real configuration error — refund and show error
    await db.update(wallets)
      .set({ availableBalance: Number(wallet.availableBalance) + amount })
      .where(eq(wallets.userId, userId));

    console.log('[Card] Config error — refunded $', amount, 'to user:', userId);

    return res.status(503).json({
      success: false,
      message: 'Card service is temporarily unavailable. Your balance has not been deducted. Please try again later.'
    });
  }

  // Other errors — refund and show exact error
  await db.update(wallets)
    .set({ availableBalance: Number(wallet.availableBalance) + amount })
    .where(eq(wallets.userId, userId));

  return res.status(400).json({
    success: false,
    message: raw.message || 'Card funding failed. Please try again.'
  });
}

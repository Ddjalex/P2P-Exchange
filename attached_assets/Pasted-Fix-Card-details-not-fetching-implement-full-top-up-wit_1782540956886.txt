Problem 2 — Implement complete top-up panel:
Backend POST /api/cards/fund:
typescript// StroWallet fund endpoint:
POST https://strowallet.com/api/bitvcard/fund-withdraw-nfccard
  ?public_key=X
  &card_id=X
  &amount=X
  &type=fund
  &mode=live

// Flow:
1. Check user platform USDT balance >= amount
2. Deduct amount from user platform balance
3. Call StroWallet fund endpoint
4. If StroWallet fails → refund amount back to user balance
5. Log: [Card] Funding card X with $Y USDT
6. Log: [Card] StroWallet fund response: {...}
7. Return success with new card balance
Backend POST /api/cards/withdraw:
typescript// StroWallet withdraw endpoint:
POST https://strowallet.com/api/bitvcard/fund-withdraw-nfccard
  ?public_key=X
  &card_id=X
  &amount=X
  &type=withdraw
  &mode=live

// Flow:
1. Call StroWallet withdraw endpoint
2. If success → add amount to user platform balance
3. If fails → return error, don't touch platform balance
4. Log: [Card] Withdrawing $Y from card X
5. Return success with new platform balance

  &mode=live

// Flow:
1. Call StroWallet freeze/unfreeze

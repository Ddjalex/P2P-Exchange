Implement StroWallet NFC Card feature for Xendrx platform
Read the StroWallet API docs at https://strowallet.readme.io/llms.txt before starting.
API endpoints to use:

Create NFC Card: POST https://strowallet.com/api/bitvcard/create-nfc-card
Get Card Details: GET https://strowallet.com/api/bitvcard/fetch-nfccard-detail
Fund/Withdraw Card: POST https://strowallet.com/api/bitvcard/fund-withdraw-nfccard
Card History: GET https://strowallet.com/api/bitvcard/nfc-card-history
Freeze/Activate: POST https://strowallet.com/api/bitvcard/freeze-unfreeze-nfccard

Auth: all requests include public_key query param from process.env.STROWALLET_PUBLIC_KEY

Step 1 — Database migration
Add to schema:
sqlCREATE TABLE IF NOT EXISTS cards (
  id SERIAL PRIMARY KEY,
  user_id INTEGER REFERENCES users(id) UNIQUE,
  card_id TEXT UNIQUE,
  card_user_id TEXT,
  customer_id TEXT,
  name_on_card TEXT,
  card_status TEXT DEFAULT 'processing',
  card_number TEXT,
  last4 TEXT,
  cvv TEXT,
  expiry TEXT,
  balance NUMERIC(10,2) DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

Step 2 — Backend routes in routes/cards.ts
POST /api/cards/create

Check user's KYC status — if NOT approved return error: "KYC verification required"
Read KYC data from database for this user:

Check existing kyc_submissions or kyc table — find the correct table name
Get: first_name, last_name, dob, id_type, id_number
Map id_type to StroWallet format: national_id → national_id, passport → passport, driver's license → drivers_license
Format dob to mm/dd/yyyy


Get user's email and phone from users table
Check user has minimum $5 USDT platform balance
Deduct $2 creation fee from user's platform USDT balance
Call StroWallet create-nfc-card:

name: full name
first_name, last_name: from KYC
dob: from KYC (mm/dd/yyyy)
id_type: from KYC (mapped)
id_number: from KYC
email: from user profile
phone: from user profile
line1: from KYC if available, else "N/A"
city: from KYC if available, else "N/A"
state: from KYC if available, else "N/A"
postal_code: from KYC if available, else "00000"
country: from KYC if available, else "ETH" — check KYC table for country field
amount_usd: "3"
mode: "sandbox"


Save card to database
Log: [Card] Creating card for user: X
Return card data

GET /api/cards/my-card

Get user's card from database
If card exists, fetch fresh details from StroWallet
Update database with latest details
Return full card details

POST /api/cards/fund

Body: { amount: number }
Check user has enough platform USDT balance
Deduct amount from user platform USDT balance
Call StroWallet fund-withdraw-nfccard with type: "fund"
Log transaction
Return success

POST /api/cards/withdraw

Body: { amount: number }
Call StroWallet fund-withdraw-nfccard with type: "withdraw"
Add amount to user platform USDT balance
Log transaction
Return success

POST /api/cards/freeze

Call StroWallet freeze/activate endpoint
Update card_status in database
Return success

GET /api/cards/history

Call StroWallet nfc-card-history endpoint
Return transaction history array

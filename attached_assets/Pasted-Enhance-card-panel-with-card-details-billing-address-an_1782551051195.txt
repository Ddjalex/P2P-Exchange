Feature 3 — Terminate Card

Add terminate card feature with password confirmation:

Backend POST /api/cards/terminate:

Since StroWallet sends a webhook when card is terminated (virtualcard.transaction.declined.terminated), implement terminate by:





Require user platform password verification first



Call StroWallet freeze endpoint with status frozen as a soft terminate



Mark card as inactive in database



Refund remaining card balance to platform wallet:

typescript

// Get card balance from StroWallet
const cardBalance = Number(card.balance);

if (cardBalance > 0) {
  // Call StroWallet withdraw to get remaining balance back
  const url = new URL('https://strowallet.com/api/bitvcard/fund-withdraw-nfccard');
  url.searchParams.set('public_key', cleanKey(process.env.STROWALLET_PUBLIC_KEY!));
  url.searchParams.set('secret_key', cleanKey(process.env.STROWALLET_SECRET_KEY!));
  url.searchParams.set('card_id', card.cardId);
  url.searchParams.set('amount', cardBalance.toString());
  url.searchParams.set('type', 'withdraw');
  url.searchParams.set('mode', 'live');
  
  const res = await fetch(url.toString(), { method: 'POST' });
  const raw = await res.json();
  console.log('[Card] Terminate withdraw response:', JSON.stringify(raw));
  
  if (raw.success) {
    // Add remaining balance to platform wallet
    await db.update(wallets)
      .set({ availableBalance: Number(wallet.availableBalance) + cardBalance })
      .where(eq(wallets.userId, userId));
  }
}

// Mark card as inactive
await db.update(cards)
  .set({ cardStatus: 'inactive', updatedAt: new Date() })
  .where(eq(cards.userId, userId));

console.log('[Card] Card terminated for user:', userId);

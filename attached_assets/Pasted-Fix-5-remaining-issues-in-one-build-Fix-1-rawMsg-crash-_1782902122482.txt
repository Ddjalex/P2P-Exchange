Fix 1 — rawMsg crash fix in routes/nfc-cards.ts:
Add this helper function at the top of the file:
typescriptfunction stroMessageToString(msg: any): string {
  if (typeof msg === 'string') return msg;
  if (msg && typeof msg === 'object') {
    return Object.entries(msg)
      .map(([k, v]) => `${k}: ${Array.isArray(v) ? v.join(', ') : v}`)
      .join(' | ');
  }
  return String(msg ?? '');
}
Then find ALL occurrences of:
typescriptconst rawMsg = stroRes?.message ?? stroRes?.error ?? "";
const lc = rawMsg.toLowerCase();
Replace with:
typescriptconst rawMsg = stroMessageToString(stroRes?.message ?? stroRes?.error ?? '');
const lc = rawMsg.toLowerCase();
This prevents the crash when StroWallet returns message as an object like {"country":["invalid"]} instead of a string. Without this fix, users lose their card creation fee silently.

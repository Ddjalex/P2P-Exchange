Fix: Change file upload storage path to persist across deployments
Problem: KYC uploaded files are being saved to a path relative to the app's working directory, which gets wiped on every deployment. Users who uploaded KYC on Replit have their files on Replit's filesystem, not on the VPS.
Fix — Change upload path in kyc.ts and messages.ts to use an absolute persistent path:
typescript// In multer configuration, change the destination:

// WRONG — relative path gets wiped on deploy:
destination: './uploads/kyc/'

// CORRECT — use env variable with absolute path:
const uploadsDir = process.env.UPLOADS_DIR || path.join(process.cwd(), 'uploads');

const kycStorage = multer.diskStorage({
  destination: (req, file, cb) => {
    const dir = path.join(uploadsDir, 'kyc');
    fs.mkdirSync(dir, { recursive: true });
    cb(null, dir);
  },
  filename: (req, file, cb) => {
    const ext = path.extname(file.originalname);
    cb(null, `${crypto.randomUUID()}${ext}`);
  }
});

const chatStorage = multer.diskStorage({
  destination: (req, file, cb) => {
    const dir = path.join(uploadsDir, 'chat');
    fs.mkdirSync(dir, { recursive: true });
    cb(null, dir);
  },
  filename: (req, file, cb) => {
    const ext = path.extname(file.originalname);
    cb(null, `${crypto.randomUUID()}${ext}`);
  }
});
On VPS, UPLOADS_DIR=/root/app/xendrx/uploads is already set in .env — so all new uploads will go directly to the persistent VPS path.

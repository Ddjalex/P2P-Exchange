Now I can see the problem clearly! StroWallet does NOT return billing address fields in the card detail response. There is no line1, city, state, postal_code in the StroWallet response.
The billing address fields we submitted during card creation are NOT returned back by StroWallet — they only store them internally for card processing.

Solution:
The billing address must be saved in your own database during card creation and displayed from there.

Fix: Billing address must be saved from card creation request — StroWallet doesn't return it
StroWallet fetch-nfccard-detail does NOT return billing address fields. The billing address submitted during card creation must be saved to our own database and displayed from there.
Fix 1 — Save billing address during card creation:
In POST /api/cards/create, after successful card creation save ALL submitted fields:
typescriptawait db.update(cards)
  .set({
    billingLine1: line1,
    billingCity: city,
    billingState: state || city,
    billingPostal: postal_code,
    billingCountry: country || 'ETH',
    billingPhone: phone || user.phone,
    reference: stroRes.response?.reference,
    customerEmail: user.email,
    updatedAt: new Date()
  })
  .where(eq(cards.userId, userId));

console.log('[Card] Saved billing address:', { line1, city, state, postal_code, country });
Fix 2 — Update existing card billing address in database:
Run this SQL on Neon to fix the existing card:
sqlUPDATE cards 
SET 
  billing_line1 = 'N/A',
  billing_city = 'N/A',
  billing_state = 'N/A',
  billing_postal = '00000',
  billing_country = 'ETH',
  billing_phone = '+251974408281',
  reference = 'CARD_CREATE_019F041681CA',
  customer_email = 'almesagadw@gmail.com'
WHERE card_id = '019f0416-81ca-7b1f-b9cc-75f0af483861';
Note: The existing card was created with N/A address because we didn't collect real address at the time. For new cards the real address will be collected and saved.
Fix 3 — Display billing address from database in frontend:
In GET /api/cards/my-card response — include billing address fields from database:
typescriptreturn res.json({
  success: true,
  card: {
    // StroWallet fields:
    cardId: card.cardId,
    cardStatus: card.cardStatus,
    cardNumber: card.cardNumber,
    last4: card.last4,
    cvv: card.cvv,
    expiry: card.expiry,
    balance: card.balance,
    nameOnCard: card.nameOnCard,
    cardBrand: card.cardBrand,
    reference: card.reference,
    customerEmail: card.customerEmail,
    createdAt: card.createdAt,

    // Billing address from OUR database:
    billing: {
      name: card.nameOnCard,
      line1: card.billingLine1 || 'N/A',
      city: card.billingCity || 'N/A',
      state: card.billingState || 'N/A',
      postalCode: card.billingPostal || '00000',
      country: card.billingCountry || 'ETH',
      phone: card.billingPhone || ''
    }
  }
});

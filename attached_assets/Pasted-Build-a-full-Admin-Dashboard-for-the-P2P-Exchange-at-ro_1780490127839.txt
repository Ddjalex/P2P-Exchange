Build a full Admin Dashboard for the P2P Exchange at route /admin. Protected by super admin login. Dark theme matching the main app (#1a1a2e background, #00d4ff neon cyan accent, Poppins font). Desktop-first layout with left sidebar navigation.

ADMIN LOGIN
Route: /admin/login

Separate login page from user login
Email + Password fields
Hardcoded super admin credentials stored in .env:
ADMIN_EMAIL=admin@ethiop2p.com
ADMIN_PASSWORD=your_secure_password

On success → redirect to /admin/dashboard
All /admin/* routes protected — redirect to /admin/login if not authenticated
Admin session stored in JWT (separate from user JWT)

GENERAL ADMIN RULES:

All admin routes require valid admin JWT (separate from user JWT)
Admin cannot use the P2P platform as a regular user (separate session)
All destructive actions (delete user, force complete order) require confirm dialog
Every admin action writes to admin_logs audit trail
Admin dashboard is desktop-first (min-width 1024px) with responsive sidebar collapse on smaller screens
Real-time stats refresh every 60 seconds using polling or WebSocket
Dark theme: #1a1a2e background, #00d4ff neon cyan accent, Poppins font
